# TechParts

### PC components for your next build

**Live website: [Open TechParts](https://velikan743.github.io/pixelforge-ecommerce-platform/)**

TechParts is a PC components storefront demo for browsing parts, comparing options, and planning a build.

The website opens with **Sign in** and **Create account** before the storefront.

## Explore the website

- Browse graphics cards, processors, motherboards, memory, storage, power supplies, cases, cooling, monitors, peripherals, and accessories.
- Search and sort the catalogue, then open product details or compare products.
- Save products to a wishlist and add items to the shopping bag.
- Try the guided PC builder, switch between light and dark themes, and explore the checkout preview.

## Demo information

This is a portfolio project and storefront preview. Catalogue prices, availability, ratings, delivery details, and compatibility need confirmation before a real sale. The bag, wishlist, and order history are browser demos; checkout does not place an order, arrange delivery, or process payment. The account service is included in this repository, but customer registration, sign-in, and admin access require the API and MongoDB to be hosted and configured.

## Built with

React and Vite power the storefront. The repository also includes an Express API and MongoDB integration for accounts, sessions, and catalogue data. GitHub Pages serves the static storefront; connect it to a hosted API and MongoDB to enable account creation and login.
